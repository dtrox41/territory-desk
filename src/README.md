# Source Structure

- `app/` — application shell, routes, providers, and global layout
- `components/` — reusable interface components
- `features/dashboard/` — action-first home experience
- `features/territory/` — territory search and routing results
- `features/representatives/` — directory and representative details
- `features/leads/` — handoff creation, ownership, status, and detail
- `features/activities/` — immutable activity timeline
- `features/followups/` — lead-derived next actions
- `features/notifications/` — in-app and provider-neutral notification behavior
- `features/insights/` — actionable collaboration insights
- `data/` — fictional prototype data and validated imports
- `services/` — integration boundaries and adapters
- `styles/` — design tokens and global styles
- `types/` — shared TypeScript contracts
- `utilities/` — small reusable helpers

Application code will be added only after the technical architecture is approved.
